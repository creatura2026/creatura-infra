1. Creer un compte

Si vous n'avez pas encore de compte, rendez-vous sur la page d'accueil publique du site. Vous y trouverez deux boutons : Creer un compte et J'ai deja un compte.

Cliquez sur Creer un compte, puis remplissez le formulaire d'inscription :

  1. Choisissez un pseudonyme — il sera visible par les autres joueurs lors des echanges.
  2. Entrez votre adresse e-mail.
  3. Choisissez un mot de passe d'au moins 8 caracteres.
  4. Cliquez sur Creer mon compte pour valider.
ℹ️

Votre pseudonyme est public et ne peut pas etre modifie apres creation. Choisissez-en un qui vous convient sur le long terme.

2. Se connecter

Si vous avez deja un compte, cliquez sur Se connecter depuis la page d'accueil ou rendez-vous directement sur /connexion.

  1. Entrez votre adresse e-mail.
  2. Entrez votre mot de passe.
  3. Cliquez sur Se connecter pour acceder a votre tableau de bord.
🔓

La session reste ouverte plusieurs jours. Vous n'avez pas besoin de vous reconnecter a chaque visite tant que vous ne vous deconnectez pas manuellement.

3. Tableau de bord (accueil)

Apres la connexion, vous arrivez sur votre tableau de bord. Il recapitule en un coup d'oeil :

  • Booster du jour — disponible ou deja ouvert.
  • Ma collection — nombre de creatures decouvertes et progression.
  • Echanges — combien attendent votre reponse.
  • Catalogue — acces rapide a toutes les cartes.

La barre de navigation en bas (sur mobile) ou sur le cote (sur grand ecran) vous permet d'acceder directement a chaque section : Accueil, Booster, Catalogue, Collection, Echanges, Profil.

4. Booster quotidien

Chaque jour, un booster gratuit est mis a votre disposition. Il contient plusieurs cartes aleatoires qui viennent enrichir votre collection.

  1. Depuis l'accueil, cliquez sur la tuile Booster du jour, ou sur Booster dans la barre de navigation.
  2. Si le booster du jour est disponible, cliquez sur Ouvrir le booster.
  3. Les cartes obtenues se revelent une par une — cliquez pour passer a la suivante.
  4. Une fois toutes les cartes affichees, elles sont automatiquement ajoutees a votre collection.
📅

Le booster se renouvelle chaque jour a minuit (heure de Paris). Si vous l'avez deja ouvert aujourd'hui, la tuile l'indique et vous invite a revenir demain.

5. Catalogue des creatures

Le catalogue liste toutes les creatures du jeu, qu'elles soient dans votre collection ou non. C'est utile pour planifier vos echanges.

Filtrer et chercher

Utilisez les filtres en haut de la page :

  • Recherche par nom — tapez les premieres lettres.
  • Famille — filtrer par type de creature (Feu, Eau, etc.).
  • Rarete — Commune, Peu commune, Rare, Tres rare, Legendaire.

Detail d'une creature

Cliquez sur une carte pour voir sa fiche : image, famille, rarete, description, et la liste des joueurs qui la possedent (utile pour proposer un echange).

6. Ma collection

La collection regroupe toutes les cartes que vous avez obtenues, y compris les doublons. Elle affiche votre progression globale.

  • Le compteur en haut indique combien de creatures differentes vous avez, sur le total disponible.
  • Les doublons (plusieurs exemplaires de la meme creature) sont visibles sur chaque carte.
  • Les doublons sont echangeables : voyez la section Echanges.
💡

Filtrez votre collection par rarete ou famille pour reperer rapidement les cartes qu'il vous manque.

7. Echanges

La fonction d'echange vous permet de proposer une de vos cartes a un autre joueur en contrepartie d'une des siennes. Les echanges se deroulent en temps reel dans une salle dediee.

Voir vos echanges en cours

Depuis Echanges, retrouvez tous vos echanges actifs. Ceux qui attendent votre reponse apparaissent en premier dans la liste.

Ouvrir un nouvel echange — par joueur

Cliquez sur Ouvrir un echange, puis choisissez l'onglet Par joueur pour trouver un joueur specifique.

  1. Tapez au moins 2 lettres du pseudonyme du joueur dans le champ de recherche.
  2. Selectionnez le joueur dans la liste de resultats.
  3. Ses cartes s'affichent. Les cartes marquees Il vous la faut sont celles absentes de votre collection.
  4. Cliquez sur Echanger avec [pseudo] pour ouvrir la salle, ou directement sur une carte pour la cibler.

Ouvrir un nouvel echange — par carte

Choisissez l'onglet Par carte si vous savez quelle creature vous voulez obtenir et souhaitez trouver un joueur qui la possede.

  1. Utilisez les filtres pour trouver la creature souhaitee dans le catalogue.
  2. Cliquez sur la carte pour afficher la liste des joueurs qui la possedent.
  3. Cliquez sur Echanger avec [pseudo] pour lancer la salle d'echange.

8. La salle d'echange

Quand une salle d'echange s'ouvre, vous et l'autre joueur vous retrouvez face a face en temps reel. Chacun choisit la carte qu'il souhaite proposer, puis les deux joueurs confirment l'accord.

  1. Posez votre carte — cliquez sur une carte de votre collection pour la mettre sur la table.
  2. Attendez que l'autre joueur pose sa carte a son tour.
  3. Confirmez l'echange une fois que les deux cartes sont posees et que les deux joueurs sont d'accord.
  4. Les cartes sont echangees instantanement et vos collections sont mises a jour.
⚠️

La salle d'echange necessite une connexion active. En cas de coupure, la page se reconnecte automatiquement. Ne fermez pas l'onglet pendant qu'un echange est en cours.

Historique des echanges

Tous vos echanges termines — conclus, refuses ou annules — sont consultables depuis Echanges › onglet Historique. Vous pouvez filtrer par statut pour retrouver un echange specifique.

9. Mon profil

La page Profil centralise vos informations personnelles, votre progression et les options de gestion de votre compte.

  • Pseudonyme, role (joueur ou administrateur) et date d'inscription.
  • Progression : nombre de creatures decouvertes sur le total disponible, pourcentage de completion et nombre total de cartes (doublons inclus).
  • Se deconnecter — ferme votre session sur cet appareil uniquement.

Les options de securite (changement de mot de passe, suppression de compte) sont disponibles plus bas sur cette meme page — voir la section Securite du compte.

10. Securite du compte

Les options de securite se trouvent sur la page Profil, dans la section Securite.

Changer de mot de passe

  1. Entrez votre mot de passe actuel pour confirmer votre identite.
  2. Saisissez le nouveau mot de passe, puis confirmez-le dans le champ suivant.
  3. Cliquez sur Changer le mot de passe.
🔒

Changer votre mot de passe deconnecte automatiquement vos autres appareils (tablette, telephone, autre navigateur). Seule la session en cours reste active.

Supprimer son compte

La suppression de compte se trouve dans la Zone sensible, tout en bas de la page Profil. Elle est definitive et irreversible : votre collection, vos identifiants et vos echanges en cours seront effaces.

  1. Faites defiler la page jusqu'a la Zone sensible.
  2. Cliquez sur Supprimer mon compte.
  3. Confirmez en saisissant votre mot de passe dans la boite de dialogue.
⚠️

Cette action est irreversible. Une fois confirme, votre compte ne peut pas etre restaure. Dans l'historique des autres joueurs, vous apparaitrez comme « Joueur supprime ».

11. Telecharger l'application

Creatura est disponible en application native pour profiter d'une experience optimale hors navigateur.

Application Windows

Depuis la page d'accueil publique, cliquez sur Telecharger pour Windows. L'installateur (.exe) est disponible dans la section Telechargements.

Application Android

Depuis un telephone Android, la page d'accueil propose directement Installer l'application Android. Le fichier .apk est disponible dans la section Telechargements.

📱

Sur Android, votre telephone peut demander d'autoriser l'installation depuis une source inconnue. Acceptez pour continuer l'installation de l'application.
